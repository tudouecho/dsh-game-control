## 4. 保存到技能库的技能

- id：`keep-on-mining-30s`
- 标题：Keep on Mining 挖矿循环（完成→下一轮→30s圆形）
- 步骤：`activate_window` → `wait_image(mining_done)` → `wait_image(next_round)` → `mouse_click` → `wait(2000)` → `mouse_circle(30s, radius=quarterWidth)`
- 模板：`<GAME_CONTROL_HOME>/templates/keep-on-mining/{start_game,start_mining,mining_done,next_round}.png`
- 面板「游戏操作 → 技能库」可查看/编辑/保存（自动备份）/恢复版本/软删除；agent 用 `game_skill` 工具复用。

## 5. 已知限制（本次验收观察）

- 挖矿轮次总时长由游戏内计时器决定；实测 30s 圆形后计时归零并出现完成面板，但若中途停顿/前台丢失会提前结束。
- 模板对窗口分辨率/DPI 敏感；换分辨率需重新裁剪。
- 沙箱内直接调用 WGC 会失败（`Failed to convert item`），插件宿主（正常权限）不受影响。
- 注入的 F12（后台进程发送）在第一次测试中未被 `GetAsyncKeyState` 捕获（可能被系统/沙箱丢弃），改用未受限后台进程后成功；真实人工按 F12 仍是最终路径。
- `skill_run` 里 `find_image` 的结果是 `{matches:[...]}`，取坐标应写 `$next.matches.0.center.x`；`wait_image` 才是 `{match:{...}}`（本次已按后者编写）。
